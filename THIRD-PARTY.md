# Third-party notices

## Backchannel

The endpoint map follows Backchannel, a userscript by Thomas Walichiewicz:
<https://github.com/twalichiewicz/Backchannel>, MIT License, Copyright (c)
2026 Thomas Walichiewicz. Its `SECURITY.md` documents what each request
carries; this module makes the same requests from a web page. Taken from
it:

- the set of endpoints;
- the exact-URL filter after Algolia's token search;
- the trailing-slash variants for the Reddit archive;
- the Constellation record paths for Bluesky.

## discueu.js

The rendering shape, a list with `.platform` and `.count` spans, descends
from discueu.js by Bèr Kessels: <https://github.com/berkes/discueu.js>,
written for the now defunct discu.eu.
